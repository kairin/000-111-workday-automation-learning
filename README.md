# Workday automation learning (migrated)

**This repository's content moved.** As of 2026-10-25, all learning notes, research
segments, source documents, and scripts that used to live here were migrated into
the private repository `000-333-workday-automation-research`, under its `learning/`
folder.

## Why

This repository is tiered public ("Learning", per the `000-111-` prefix in the
`000-0-manifest` classification rules). Its content scope — browser automation
learning relevant to Workday — overlapped with the private
`000-333-workday-automation-research` repository's existing research scope.
Consolidating into the private repository removes the duplication; moving
*public* content into a *private* repository carries no disclosure risk (the
reverse direction would have).

## Where the content is now

See `000-333-workday-automation-research/learning/` (private repo, not accessible
from this public one). It includes:

- `docs/segments/01-08` — the eight research segments
- `docs/sources/` — the original source reports, unchanged
- `docs/baseline/`, `docs/review/`, `docs/recommendations.md`, `docs/tasks.md`
- `scripts/check-links.py`, `scripts/check-records.py`

## Status

This repository is retired and retained as a read-only archived pointer to the
new location. New work belongs in the private research repository. Earlier
versions remain available in this public repository's Git history.
